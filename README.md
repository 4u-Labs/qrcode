# 📱 QR Code Studio Pro 2.0

Gerador e Scanner de QR Code avançado e moderno desenvolvido com HTML5, CSS3, Canvas API e JavaScript Puro pela **4U.IA.BR Labs**.

🔗 **Acesse e use online:** [https://4u.ia.br/app/qrcode/](https://4u.ia.br/app/qrcode/)

---

## 🌟 Funcionalidades Principais

- 💠 **PIX Oficial (Banco Central / EMVco)**: Geração de QR Code estático do Pix com cálculo exato de CRC16, validação de chaves e botão "Copiar Código Pix Copia e Cola".
- ⚡ **Live Preview em Tempo Real**: O QR Code é renderizado e atualizado instantaneamente enquanto você digita (split-screen no desktop).
- 🖼️ **Logotipo / Marca no Centro**: Suporte a ícones predefinidos (Pix, WhatsApp, Wi-Fi, Instagram, 4U, Link) ou upload de imagem própria com proteção de erro nível H.
- 🖨️ **Molduras para Impressão**: Molduras de balcão (*"ESCANEIE AQUI"*, *"PAGUE COM PIX"*, *"CONECTE-SE AO WI-FI"* ou texto personalizado).
- 📋 **Placa para Display de Mesa (A4/A5)**: Modal de impressão pronto para displays acrílicos de restaurantes, balcões e recepções.
- 📷 **Scanner / Leitor Integrado**: Decodificação via câmera em tempo real (webcam/smartphone) ou upload de imagem/print.
- 📐 **Múltiplos Formatos de Download**: Exportação em **PNG em alta resolução** e **SVG vetorial infinito**.
- 📶 **Diversos Tipos de Conteúdo**: Links (URL), WhatsApp Direct, Wi-Fi com senha, vCard (contato), Google Maps, E-mail, SMS, Texto plano e Criptomoedas.
- 📜 **Histórico Local**: Salva os últimos códigos no navegador (`localStorage`) para restauração em 1 clique.
- 📱 **PWA & Offline Ready**: Service Worker com estratégia Network-First e Web App Manifest.

---

## 🛠️ Stack Tecnológica

- **Frontend**: Vanilla JavaScript (ES6+), HTML5 Canvas, Bootstrap 5, FontAwesome 6, CSS3 Moderno (Glassmorphism & Flex/Grid).
- **QR Code Engine**: QRCode.js & Canvas Compositing Engine.
- **Scanner**: Html5-QRCode.
- **Privacidade**: 100% Client-side (Zero retenção de dados no servidor).
